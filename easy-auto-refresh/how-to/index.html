auto refresh tab chrome extension

Set a reload interval and click Start — the tab refreshes itself until you stop it.

Get the extension

Step by step

  1. Click the Easy Auto Refresh icon in your toolbar
  2. Type an interval (e.g. 30 for 30 seconds) and choose seconds/minutes
  3. Click Start — the badge counter tracks each reload
  4. Click Stop or press the keyboard shortcut to pause
  5. Toggle notifications on in the popup if you want OS alerts

FAQ

Does it work after I close the popup?

Yes — alarms run in the background independently of the popup.

Will it reload tabs I didn't set it on?

No — each tab has its own independent timer; other tabs are untouched.

Does the interval survive a browser restart?

Yes — alarms are persisted by Chrome and resume automatically.

Can I use a keyboard shortcut?

Yes — set it in chrome://extensions/shortcuts; it toggles start/stop on the active tab.
