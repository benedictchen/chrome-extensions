Step by step

  1. Navigate to any page containing a table or repeated list.
  2. Click the TableSnap icon in the Chrome toolbar.
  3. Review the detected data in the popup preview grid.
  4. Click 'Export CSV' (or 'Export Excel') — the file downloads instantly.
  5. For SPA pages, scroll to load more rows, then re-preview to capture them.

FAQ

Does it work on dynamic/SPA pages?

Yes — MutationObserver tracks newly added rows automatically; just re-open the popup after scrolling.

Is my data sent anywhere?

No. Everything is processed locally and exported directly to your device. Zero network calls.

Do I need an account?

No account required. Free for the first 10 extractions.

What file formats are supported?

CSV and XLSX — both generated fully client-side.

Why does it ask for scripting permission?

To read the DOM of the tab you are actively viewing — no background access, no other sites.
