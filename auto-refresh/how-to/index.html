Step by step

  1. Click the extension icon on any http/https tab
  2. Set your refresh interval in seconds or minutes
  3. Click Start — the badge counts each reload
  4. Click Stop to halt, or press the keyboard shortcut to toggle without opening the popup
  5. Interval settings persist automatically and resume after browser restart

FAQ

Does it work after browser restart?

Yes — intervals are saved via chrome.alarms and resume automatically.

Can I refresh multiple tabs simultaneously?

Click the extension on each tab individually to set independent intervals per tab.

Why no notifications by default?

Badge counter is the default feedback; enable OS notifications in popup settings if preferred.

Does it work on chrome:// or chrome-extension:// pages?

No — Chrome restricts extensions on system pages; a graceful error is shown instead of crashing.
