Get the extension

Step by step

  1. Install PhishGuard from the Chrome Web Store
  2. Click the extension icon and confirm the toggle shows protection active
  3. Browse normally — blocked URLs trigger a notification and never load page content
  4. Check the popup for cumulative block count and current ruleset version

FAQ

Does this read my browsing history?

No. PhishGuard never requests history, cookies, or browsingData — all blocking runs via a local DNR ruleset with no data leaving your browser.

Why is no installer or binary required?

All URL matching runs inside the Chrome extension sandbox via declarativeNetRequest; no native component is needed or installed.

How is the blocklist updated?

Updates ship as standard Chrome Web Store extension updates — versioned DNR ruleset, zero network telemetry.

What if a legitimate site is blocked?

The block page includes a one-session bypass link; use the popup feedback button to report a false positive.
