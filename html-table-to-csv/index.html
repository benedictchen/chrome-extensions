HTML Table → CSV

Paste an HTML table (or its <table> markup) below. Get clean CSV to download, or TSV to paste straight into Google Sheets / Excel. Runs entirely in your browser — nothing is uploaded, no sign-up.

Paste a table, then click “Parse table”.
Need a table off a live page — behind a login, across pagination, or auto-refreshed? A web page can’t read another site. Get the data-scraper Chrome extension →
How do I convert an HTML table to CSV without code?

Select the table on the page, copy it, paste into the box above, and click Parse then Download CSV. It all happens locally in your browser.

Paste straight into Google Sheets / Excel?

Click “Copy as TSV”, then paste into a sheet — each column lands in its own cell.
